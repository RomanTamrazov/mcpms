# Интеграция модели «Износ инфраструктуры»

В сайт подключён только артефакт `maintenance_lgbm.joblib` из переданного
архива. Он оценивает прокси-метку `y_repair_7d` на горизонте 168 часов. Модели
инцидентов из того же архива относятся к другим направлениям и здесь не
регистрируются.

## Метрики из артефакта

- тест 2026: Precision `0.758886`, Recall `0.743800`, PR-AUC `0.839173`;
- рабочий порог: `0.5007203849446524`;
- тестовых строк: `1 178 774`, положительных: `325 558`;
- 33 признака, включая историю канала и агрегаты соседних каналов объекта;
- целевые и будущие колонки из Parquet в признаки не входят.

Архив не объясняет, как `y_repair_7d` подтверждалась реальными ремонтами или
решениями ОДС. Поэтому API маркирует результат как `maintenance_proxy_score`,
а не как подтверждённую вероятность физического износа.

Приложенный `latest_table.parquet` содержит по одной последней строке для
каждого из 12 621 каналов. Времена этих строк лежат в диапазоне от
`2019-01-08 03:00:00` до `2026-06-30 23:00:00`: это демонстрационный срез, а
не поток актуальной телеметрии. Для эксплуатации сайта его нужно регулярно
заменять либо передавать рассчитанные на текущий момент 33 признака через API.

## Вызов

```json
{
  "channel_id": 330565,
  "display": {
    "object_name": "Название объекта",
    "district": "ЮАО",
    "picket": "ПК 130"
  }
}
```

Для вызова общего API поля отображения передаются во внешней оболочке:

```json
{
  "payload": {"channel_id": 330565},
  "display": {"object_name": "Название объекта", "district": "ЮАО"}
}
```

Также принимается `features` с точным набором 33 колонок из metadata модели и
обязательным `features_as_of`. Произвольные и недостающие колонки отклоняются.
По умолчанию API принимает признаки не старше 24 часов; лимит задаётся
`ML_MAX_FEATURE_AGE_HOURS`. Старый встроенный Parquet отклоняется. Режим
`ML_ALLOW_HISTORICAL_SCORING=1` предназначен только для воспроизведения тестов
и демонстрации, но не должен включаться в рабочем контуре.

Исходные SHA-256:

- `maintenance_lgbm.joblib`: `ab1ae9dba65a360b71f753137dfb07b080ecf4a5e47b834de337bdd9c07a5a77`;
- `latest_table.parquet`: `f12b96c9d9139c85900f2b13f5714290926a28e3fc052910c4ef1189f813e85b`.
