# Папки моделей

Каждая классификация живёт независимо в `models/<model_id>/` и содержит:

- артефакты модели;
- собственные зависимости, если они отличаются от общих;
- адаптер с `describe()` и `predict(payload, display)`;
- README с входной схемой, горизонтом, метриками и ограничениями.

Адаптер возвращает исходный результат и карточку по контракту
`website/ML_API_CONTRACT.md`. Не настроенные модели остаются видимыми в
`GET /api/v1/models` со статусом `not_configured` и не генерируют фиктивные
оценки.

Подключены:

- `fire_risk/` — риск нового срабатывания дымового датчика, 336 часов;
- `infrastructure_wear/` — прокси-скор необходимости обслуживания канала,
  168 часов.
- `unauthorized_access/` — риск охранной SCADA-тревоги на следующий
  календарный день и ранжирование зон, 24 часа.
